# App policies — Ahmet Duman

A shared privacy and support website for apps by Ahmet Duman. Each app has its own policy so that its disclosures match its actual functionality and services.

Published website: https://ahmwtdmn.github.io/app-policies/

## Pages

- HazeCam privacy, English: https://ahmwtdmn.github.io/app-policies/hazecam/privacy/
- HazeCam privacy, Turkish: https://ahmwtdmn.github.io/app-policies/hazecam/privacy/tr/
- Developer support: https://ahmwtdmn.github.io/app-policies/support/

## Hosting

GitHub Pages publishes `docs/` on the `main` branch. The site uses static HTML and local CSS, with no build dependencies, client-side scripts, contact forms, advertising or analytics scripts. GitHub's hosting infrastructure handles technical request data under its own privacy statement.

## Add another app

1. Confirm the app's actual permissions, local storage, network requests, third-party SDKs, purchases and data-retention/deletion behavior.
2. Add an app-specific directory under `docs/`, following `docs/hazecam/privacy/`.
3. Write that app's own accurate privacy policy. Do not reuse another app's service or data claims without checking them.
4. Add its link to the directory on `docs/index.html` and to `docs/sitemap.xml`.
5. Publish and verify the exact page before using the URL in the app or store listing.
